
# StudySync - Student Productivity Tracker

## 1. Introduction
StudySync is a student productivity website designed
to help students organize daily tasks, study schedules,
and coding practice.

## 2. Objectives
- Organize daily study tasks.
- Track completed tasks and progress.
- Display a weekly study timetable.
- Track coding practice.
- Save progress in the browser.

## 3. Technologies Used
- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## 4. Main Features
- Student dashboard
- Daily task checklist
- Automatic progress calculation
- Study timetable
- Coding progress tracker
- Responsive layout

## 5. How to Run
1. Open the project folder in VS Code.
2. Open index.html using a browser
   or the Live Server extension.
3. Use the dashboard and test its features.

## 6. Future Improvements
- Add new tasks dynamically.
- Add a daily study reminder.
- Store more study statistics.
- Add user accounts in a future version.

## 7. Conclusion
StudySync demonstrates how HTML, CSS, and JavaScript
can be combined to build a useful student productivity
website.
